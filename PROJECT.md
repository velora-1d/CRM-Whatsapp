# WA-CRM

## Deskripsi
Self-hostable CRM template untuk WhatsApp dengan shared inbox, kontak, pipeline penjualan, broadcast, dan otomatisasi no-code.

## Stack Teknologi
- Frontend : Next.js 16 (React 19) + Tailwind CSS v4
- Backend  : Next.js API Routes (Serverless)
- Database : Supabase (PostgreSQL)
- ORM      : Supabase Client SDK
- Auth     : Supabase GoTrue Auth
- Hosting  : Local (Development) / Hostinger Node.js / Vercel
